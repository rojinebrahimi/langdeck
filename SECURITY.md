# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/rojinebrahimi/langdeck/security/advisories/new).

Include the affected version, a description, reproduction steps and the impact you
expect. We aim to acknowledge reports within 3 business days and to ship a fix for
confirmed high-severity issues within 30 days. We will credit you in the advisory unless
you prefer otherwise.

## Supported versions

Security fixes land on the latest minor release. Upgrade to stay covered.

## Hardening guide

See [docs/security.md](docs/security.md) for the threat model and the production checklist
